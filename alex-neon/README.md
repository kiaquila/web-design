# Alex Neon — «ИИ по делу»

Премиальный тёмный редизайн действующего лендинга Алексея Грищенко об
индивидуальных занятиях по практической работе с ИИ.

- Оригинал: <https://codex-po-delu-alex.alexgoodmanalexgoodm.chatgpt.site/>
- Стенд: `https://alex-neon.ks-design.workers.dev` (после одноразового
  подключения Worker'а владельцем аккаунта — см.
  [`docs/stage-hosting.md`](../docs/stage-hosting.md))

## Deliverable

Одностраничный статический лендинг в [`website/`](./website/): контент оригинала
перенесён дословно, дизайн полностью новый, включая два интерактивных
нейро-поля — в hero и в блоке «Как проходит обучение».

## Концепция «Alex Neon»

- Почти чёрный фон, светлая типографика, воздух; неон — акцент, а не заливка.
- Один акцентный градиент: лазурно-бирюзовый → фиолетовый. Других цветов нет.
- Дисплейная гарнитура Unbounded (заголовки, монограмма), текстовая Manrope.
  Обе — variable woff2, кириллица+латиница, self-hosted, SIL OFL 1.1.
- Знак — логотип **ALEX OXITOCIN**, перерисованный по образцу заказчика:
  лазурный «ALEX», фиолетовый «OXITOCIN». Один инлайновый SVG-символ на шапку
  и футер.
- Интерактив: два canvas-поля — статичные, без вращения. Структура дендритная:
  из ядра расходятся ветвящиеся нити, узлы разного калибра — от почти
  невидимых вдоль нити до крупных сом на концах. Под курсором нейроны
  загораются, и заряд идёт дальше по связям. При `prefers-reduced-motion` —
  статичный рендер.
- В hero фигура — круг с прерывистым ободом и разреженной серединой. Он
  размещается в свободной колонке рядом с текстом и никогда его не задевает;
  на узких экранах уходит под нижний край hero и виден верхней дугой.
- В блоке «Как проходит» у каждого шага свой нейрон, который откликается на
  наведение на пункт.

## Источники истины

- [`CONTENT-AUDIT.md`](./CONTENT-AUDIT.md) — канонический контент, провенанс,
  осознанные отклонения.
- [`AGENTS.md`](./AGENTS.md) — правила реализации и проверки.
- `website/src/styles/tokens.css` — токены дизайн-системы; слои `base`,
  `layout`, `components`, `sections` собираются поверх них в этом порядке.

## Решения

- Секции, порядок, якоря `#examples/#control/#process/#about/#contact`,
  внешние ссылки (2×Telegram, LinkedIn) — как в оригинале.
- Видео-блок остаётся заглушкой «Видео готовится» — ролика в источнике нет.
- `og.png` генерируется из нового hero; фавикон — монограмма «A».
- Никаких сетевых зависимостей: шрифты и статика только со своего origin,
  без аналитики и трекеров (как и в оригинале).
- `assets/og.png` не хранится «как есть»: он воспроизводимо генерируется
  `npm --prefix alex-neon/website run og` — тем же генератором поля
  (`src/js/field.js`), что и hero, на чистом Node без шрифтов и внешних
  библиотек. Поэтому карточка не расходится с страницей.
- Логотип Telegram-сообщества хостится локально
  (`assets/community-mark.jpg`, 176×176, 9 КБ) — внешних запросов нет.
- Бюджет первой отрисовки: HTML + CSS + JS ≈ 26 КБ в gzip плюс три
  предзагружаемых woff2 (~70 КБ). Проверяется тестом.

## Открытые вопросы

- Подключение Cloudflare Worker `alex-neon` — одноразовый шаг владельца
  аккаунта по [`docs/stage-hosting.md`](../docs/stage-hosting.md).
- Индексация стенда: сейчас `robots.txt` разрешает обход (как у других
  проектов); если оригинал остаётся боевым, возможно, стоит закрыть стенд от
  индексации, чтобы не создавать дубль. Решение за заказчиком.
- Реальный YouTube-ролик для блока «Короткая демонстрация».

## Проверки

Из корня репозитория:

```bash
node scripts/check-repository.mjs
npm --prefix alex-neon/website run check
```

Локальный просмотр: `npm --prefix alex-neon/website run dev`
(<http://localhost:4600>).

Для визуальных изменений дополнительно проверять 360 px и 1280 px+, состояние
фокуса с клавиатуры, раскрытие FAQ, `prefers-reduced-motion` и поведение
canvas-анимации при наведении, касании и скролле.
